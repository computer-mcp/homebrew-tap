# Computer-mcp Tap

## How do I install these formulae?

`brew install computer-mcp/tap/<formula>`

Or `brew tap computer-mcp/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "computer-mcp/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
